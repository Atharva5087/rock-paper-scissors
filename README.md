🎮 **Rock Paper Scissors**

A simple yet fun command-line Python game where you play Rock, Paper, Scissors against the computer. The program takes your input, generates a random choice for the computer, and declares the winner. Perfect for beginners learning Python fundamentals.

---

## 🧠 Features
- Interactive command-line input  
- Random computer choices  
- Clear win/tie result logic  
- Beginner-friendly and easy to extend  

---

## 🧩 How It Works
1. The player is prompted to choose between **rock**, **paper**, or **scissors**.  
2. The computer randomly selects one of the three options.  
3. The program compares both choices and prints the result — win, lose, or tie.
